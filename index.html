How the oracle works

A logistic-regression model was built from scratch with batch gradient descent. It uses class, recorded sex, age, family members, fare, and port of embarkation. The number shown is a probability estimate, not a fact or a judgment.

This interactive is an educational analysis of historical data. The model reflects patterns and biases in its 1912 passenger record; it must not be used to make decisions about people.
